# Habesha Coffee & Spice Market (Habesha Store)

An authentic Ethiopian eCommerce store built with Next.js App Router, TypeScript, and Tailwind CSS following the IBT College CodeOps Roadmap.

## Features
- Catalogue: Browse Ethiopian coffees, spices, and crafts.
- Product Details: Dynamic /products/[id] routes with full details.
- Shopping Cart: Global CartContext with localStorage persistence.
- Dedicated Checkout: Validated customer and delivery form at /checkout.
- Order Confirmation: Itemized receipt at /order-success.

## Commands
npm install
npm run dev
npm run build
